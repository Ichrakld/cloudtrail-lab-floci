# Sources de travail et provenance

Ce laboratoire personnel reprend les objectifs pédagogiques et la distinction des sources documentés dans :

- Dépôt Floci de référence : https://github.com/othmane71-art/cloudtrail-lab
- Archive pédagogique fournie : version antérieure fondée sur LocalStack.
- Support de TP fourni : [`reference/TP_CloudTrail.pdf`](reference/TP_CloudTrail.pdf).

La version actuelle du laboratoire personnel utilise Floci sous Kali. Les étapes et le format du projet ont été adaptés au déroulé visible dans `docs/screenshots/`. L’archive ZIP reposait sur LocalStack et certaines commandes ne s’appliquent pas à la version Floci : seuls le support de TP et les objectifs utiles ont été conservés. Les captures correspondent aux manipulations effectuées localement par l'auteur de ce dépôt.

Le dépôt de référence est conservé comme source d'inspiration ; consulter sa page pour ses auteurs et conditions de réutilisation. Aucun résultat de Floci n'est présenté comme un résultat AWS réel.
